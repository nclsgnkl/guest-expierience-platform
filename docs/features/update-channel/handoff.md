### Deviations this session (recorded, none reopens a design decision)
9. **`ExchangeFiles.readState` returns `UpdaterState(dto, lastRequestedAt)`**, not the bare DTO — the reconcile rule needs `state.lastRequestedAt`, which the contract deliberately omits. The DTO is mapped 1:1 otherwise.
10. **Test seams on `UpdateControl`** (package-private `useClock(Clock)`, `useBaseUrl(String, boolean)`): the design foresaw a per-profile base URL; the not-configured / insecure / closed-port cases would each cost a Quarkus boot (~60 s on the Pi), so the Control reads the base URL from a volatile field initialised from config and tests override it. Production never calls them (package-private, `%test` classes only).
11. **`ManifestServer` is suite-wide** (`@QuarkusTestResource` without `restrictToAnnotatedClass`): one boot, and `gxp.update.base-url` is therefore SET for every `@QuarkusTest` (serving 404 unless a test `serve`s something). Consequence: `GET /api/manager/updates` reports `configured: true` in the suite; the scheduler is `halted`, so no check ever fires by itself.
12. **Reconcile "same window" rule refined**: the file is kept when it matches (version, `auto`) AND its window has not passed AND (`applyNotBefore ≤ now` — the window is open — OR `applyNotBefore == next`). The design's version would have kept a stale future time after the manager changed `applyAt`; `ReconcileTest.aChangedApplyTimeMovesAFutureWindow` pins the refinement.
13. **Log policy in `runCheck`**: `NO_UPDATE` and `NOT_CONFIGURED` are silent (an unconfigured box would otherwise warn hourly); every other outcome logs `Update check failed: <code>` (+ class name for transport failures). Nothing else on the path logs.
14. **Unchanged `PUT /settings` leaves one field-less audit row** — that is `AuditControl.record`'s contract for an empty change list and exactly what `PropertyControl.update` does; pinned in `UpdateApiTest` rather than special-cased.
15. **`state-in-progress.json` added** to the fixture set (step 5 of the updater writes it; the outcome list in §2 omitted it). `ExchangeFilesTest` expects 13 state fixtures.
16. **`decodeSignature`** (Control): the `.sig` body is stripped, regex-checked against the base64 pattern, decoded, and must be exactly 64 bytes — otherwise `INVALID_SIGNATURE` without touching the verifier.
17. `updateSettings` validates `applyAt` a second time (`LocalTime.parse` → 400 `validation-failed`) behind the contract's bean validation — defensive only.
